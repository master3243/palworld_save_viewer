# Demo save catalog

`catalog.json` lists my original demo and 34 alternatives. The application downloads the catalog when the picker opens and downloads save files only when the user confirms a selection. My original demo is in `resources/example_save/`.

Uploader names identify the source account that shared the save, rather than the in-game character. Names come from the linked source pages and the sandbox collection notes.

After changing saves or tracker scoring, run `node scripts/update-demo-summaries.cjs` from `pal-storage-viewer` to recompute stats.

The Pal count is the number of rows loaded into the Pal table from all files included in the demo.
